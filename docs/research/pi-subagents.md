# Research note: `pi-subagents`

**Evidence base.** Source checkout `/tmp/pi-subagents-research`, revision [`4745bd0e42083b2e2d6165ed70702c751cbfaca7`](https://github.com/nicobailon/pi-subagents/tree/4745bd0e42083b2e2d6165ed70702c751cbfaca7), plus this repository's official Pi docs. “Fact” means directly documented or implemented; “Inference” is a conclusion from those facts; “Open question” is not settled by the inspected sources.

## Architecture and workflows

- **Fact:** `index.ts` is the package entry point and refuses to register the parent extension when `PI_SUBAGENT_CHILD=1`. The parent registers the `subagent` tool, `subagent_wait`, slash commands, FleetView, RPC, supervisor channel, and result watcher in [`src/extension/index.ts`](https://github.com/nicobailon/pi-subagents/blob/4745bd0e42083b2e2d6165ed70702c751cbfaca7/src/extension/index.ts#L393-L463).
- **Fact:** Public execution accepts either `{ agent, task }` or a JavaScript `workflowScript`; orchestration is `await runs.run(...)` for sequence and `await runs.all(...)` for ordinary fanout. Legacy top-level `chain`, `tasks`, and `parallel` fields are rejected ([`src/extension/public-execution.ts`](https://github.com/nicobailon/pi-subagents/blob/4745bd0e42083b2e2d6165ed70702c751cbfaca7/src/extension/public-execution.ts#L28-L77), [`docs/workflows.md`](https://github.com/nicobailon/pi-subagents/blob/4745bd0e42083b2e2d6165ed70702c751cbfaca7/docs/workflows.md#scripted-workflows-workflowscript)). Users can ask naturally, use `/run`, or invoke RPC. Background execution is the normal workflow default; `async:false` blocks the parent ([`docs/tool-reference.md`](https://github.com/nicobailon/pi-subagents/blob/4745bd0e42083b2e2d6165ed70702c751cbfaca7/docs/tool-reference.md#parameter-reference)).
- **Fact:** A child is a separate Pi process. `src/runs/shared/pi-args.ts` builds `--model`, `--tools`/`--no-tools`, extension/context/skill flags, system-prompt files, task delivery, and coordination environment; foreground execution spawns it with piped JSONL ([`src/runs/shared/pi-args.ts`](https://github.com/nicobailon/pi-subagents/blob/4745bd0e42083b2e2d6165ed70702c751cbfaca7/src/runs/shared/pi-args.ts#L572-L649), [`src/runs/foreground/execution.ts`](https://github.com/nicobailon/pi-subagents/blob/4745bd0e42083b2e2d6165ed70702c751cbfaca7/src/runs/foreground/execution.ts#L526-L538)).

## Lifecycle and result handoff

- **Fact:** Background runs have `status.json`, `events.jsonl`, human-readable logs, output logs, and result JSON. The runner records terminal state and publishes the result through an indexed pending-file then atomic promotion ([`src/runs/background/subagent-runner.ts`](https://github.com/nicobailon/pi-subagents/blob/4745bd0e42083b2e2d6165ed70702c751cbfaca7/src/runs/background/subagent-runner.ts#L2277-L2310), [same file](https://github.com/nicobailon/pi-subagents/blob/4745bd0e42083b2e2d6165ed70702c751cbfaca7/src/runs/background/subagent-runner.ts#L5180-L5230), [`src/runs/background/result-files.ts`](https://github.com/nicobailon/pi-subagents/blob/4745bd0e42083b2e2d6165ed70702c751cbfaca7/src/runs/background/result-files.ts#L169-L177)).
- **Fact:** The parent watcher filters delivery by owning session and completion owner, reads results, emits notifications/intercom, and consumes the one-shot public result while retaining bounded replay/archive state ([`src/runs/background/result-watcher.ts`](https://github.com/nicobailon/pi-subagents/blob/4745bd0e42083b2e2d6165ed70702c751cbfaca7/src/runs/background/result-watcher.ts#L167-L205), [`docs/observability.md`](https://github.com/nicobailon/pi-subagents/blob/4745bd0e42083b2e2d6165ed70702c751cbfaca7/docs/observability.md#async-run-artifacts)). Workflow children hand off via returned `output`, `structuredOutput`, saved output paths, and artifact/session paths; supervisor asks use `contact_supervisor` rather than routine completion messages ([`docs/workflows.md`](https://github.com/nicobailon/pi-subagents/blob/4745bd0e42083b2e2d6165ed70702c751cbfaca7/docs/workflows.md#supervisor-coordination-child-asks-parent)).
- **Fact:** `resume` starts a new child process from a persisted session, requires resumable state and an exclusive session lease; `stop` is terminal/non-resumable ([`docs/tool-reference.md`](https://github.com/nicobailon/pi-subagents/blob/4745bd0e42083b2e2d6165ed70702c751cbfaca7/docs/tool-reference.md#resume), [same](https://github.com/nicobailon/pi-subagents/blob/4745bd0e42083b2e2d6165ed70702c751cbfaca7/docs/tool-reference.md#stop)). **Open question:** notification delivery depends on the host session remaining alive; the docs explicitly say detached work continues but its wake can be lost ([`docs/extension-api.md`](https://github.com/nicobailon/pi-subagents/blob/4745bd0e42083b2e2d6165ed70702c751cbfaca7/docs/extension-api.md#host-session-lifetime-and-completion-wakes)).

## Isolation and security

- **Fact:** Default children share the selected `cwd`. `worktree:true` creates Git worktrees/branches, requires a clean repository, and captures diffs/handoff; its base directory cannot be inside Pi's auto-discovered extensions directory ([`src/runs/shared/worktree.ts`](https://github.com/nicobailon/pi-subagents/blob/4745bd0e42083b2e2d6165ed70702c751cbfaca7/src/runs/shared/worktree.ts#L135-L145), [same](https://github.com/nicobailon/pi-subagents/blob/4745bd0e42083b2e2d6165ed70702c751cbfaca7/src/runs/shared/worktree.ts#L197-L210)). Capability ceilings intersect allowed tools/agents and can deny extensions, including for nested children ([`src/runs/shared/capability-ceiling.ts`](https://github.com/nicobailon/pi-subagents/blob/4745bd0e42083b2e2d6165ed70702c751cbfaca7/src/runs/shared/capability-ceiling.ts#L140-L165)).
- **Fact:** The `tools` field is a strict child registry allowlist, not an extension loader; missing tools fail launch ([`src/runs/shared/tool-availability.ts`](https://github.com/nicobailon/pi-subagents/blob/4745bd0e42083b2e2d6165ed70702c751cbfaca7/src/runs/shared/tool-availability.ts#L60-L75)). Pi itself has no built-in sandbox; tools and extensions run with the parent user's permissions ([`packages/coding-agent/docs/security.md`](../../packages/coding-agent/docs/security.md)).
- **Inference:** Worktrees isolate ordinary file changes, and ceilings reduce accidental capability, but neither is an OS security boundary. A child with `bash` or a mutating extension can escape the intended role through local processes, credentials, or paths. Use an OS/container boundary for hostile or unattended work.

## Model and config inheritance

- **Fact:** Agent discovery precedence is builtin, package, user, then project, with project winning collisions ([`src/agents/agent-selection.ts`](https://github.com/nicobailon/pi-subagents/blob/4745bd0e42083b2e2d6165ed70702c751cbfaca7/src/agents/agent-selection.ts#L1-L22)). Effective model precedence is per-run, agent frontmatter, settings override/default, then the parent session model; bare ids may use a configured provider, while `provider/id` is explicit ([`docs/models.md`](https://github.com/nicobailon/pi-subagents/blob/4745bd0e42083b2e2d6165ed70702c751cbfaca7/docs/models.md#models), [`src/runs/shared/model-fallback.ts`](https://github.com/nicobailon/pi-subagents/blob/4745bd0e42083b2e2d6165ed70702c751cbfaca7/src/runs/shared/model-fallback.ts#L287-L330)). Fallback models apply to provider/model failures, and model scopes or thinking ceilings can reject candidates before launch.
- **Fact:** `systemPromptMode`, project-context inheritance, skills, tools, extensions, output, and default context are separate launch-contract fields. `fork` is a real branched session when available; implicit fork may fall back to fresh, while explicit fork is strict ([`src/api/preflight.ts`](https://github.com/nicobailon/pi-subagents/blob/4745bd0e42083b2e2d6165ed70702c751cbfaca7/src/api/preflight.ts#L353-L442), [`docs/tool-reference.md`](https://github.com/nicobailon/pi-subagents/blob/4745bd0e42083b2e2d6165ed70702c751cbfaca7/docs/tool-reference.md#fork-context-details)).

## Executable capability versus system-prompt instructions

- **Fact:** Builtin role Markdown is system-prompt guidance plus frontmatter. `reviewer` exposes only `read, grep, find, ls`, so its read-only behavior is executable at the tool-registry level. `scout` exposes `bash, write`, and `oracle` exposes `bash`, despite prompts saying to inspect or not edit ([`agents/reviewer.md`](https://github.com/nicobailon/pi-subagents/blob/4745bd0e42083b2e2d6165ed70702c751cbfaca7/agents/reviewer.md), [`agents/scout.md`](https://github.com/nicobailon/pi-subagents/blob/4745bd0e42083b2e2d6165ed70702c751cbfaca7/agents/scout.md), [`agents/oracle.md`](https://github.com/nicobailon/pi-subagents/blob/4745bd0e42083b2e2d6165ed70702c751cbfaca7/agents/oracle.md)).
- **Fact:** pi-subagents explicitly refuses to apply its permission rules to `bash`; it delegates bash policy to `pi-guard`, and `permissionDecision` returns `allow` for bash ([`src/runs/shared/permissions.ts`](https://github.com/nicobailon/pi-subagents/blob/4745bd0e42083b2e2d6165ed70702c751cbfaca7/src/runs/shared/permissions.ts#L21-L52)).
- **Inference:** A prompt can shape behavior but cannot remove an executable capability. The reliable control order is OS/container isolation, Pi/extension tool registry, capability ceiling, then model instructions. Treat “read-only” in a role prompt as an intent unless the allowlist and host policy enforce it.

## Known limitations

- **Fact:** External CLI runners are async-only and do not support Pi models/tools/extensions, skills, structured output, nested subagents, fallback models, steer, or resume ([`docs/extension-api.md`](https://github.com/nicobailon/pi-subagents/blob/4745bd0e42083b2e2d6165ed70702c751cbfaca7/docs/extension-api.md#external-cli-agent-profiles)). `pi.events` is in-process only, not a cross-process bus ([same](https://github.com/nicobailon/pi-subagents/blob/4745bd0e42083b2e2d6165ed70702c751cbfaca7/docs/extension-api.md#scope)).
- **Fact:** Workflow scripts must observe every launch, use portable JavaScript constraints, and do not expose raw child directories or session files ([`docs/tool-reference.md`](https://github.com/nicobailon/pi-subagents/blob/4745bd0e42083b2e2d6165ed70702c751cbfaca7/docs/tool-reference.md#workflow-steering)).
- **Open question:** The inspected sources do not establish a stronger security boundary for extension code, `bash`, symlinked dependencies, or inherited credentials than Pi's general local-user trust boundary. Pi's official guidance is to use containers, VMs, or policy sandboxes when stronger isolation is needed ([`packages/coding-agent/docs/security.md`](../../packages/coding-agent/docs/security.md)).
